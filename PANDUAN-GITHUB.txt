================================================
  MIAPOS — PANDUAN GITHUB & UPDATE APLIKASI
  (dipperbarui untuk v2.10 — dibikin detail biar jelas)
================================================

PRINSIP DASARNYA CUMA 1
-----------------------
Web kamu live di Vercel karena tersambung ke repo GitHub.
Jadi update aplikasi = TIMPA FILE DI REPO, selesai. Vercel
otomatis deploy ulang (±1 menit), lalu app di semua HP
pengguna update sendiri lewat service worker (sw.js).
TIDAK PERLU uninstall app di HP. Sekali install, selamanya.

ada otomatis kebikin. Aman 100%.

== CARA A — LEWAT WEBSITE GITHUB (paling gampang, tanpa Termux) ==
1. Extract zip Miapos terbaru di HP/PC kamu.
2. Buka github.com → masuk repo miapos kamu.
3. Klik "Add file" → "Upload files".
4. Drag SEMUA file di root (luar folder) — v2.10 artinya:
      index.html, sw.js, manifest.json, favicon.ico,
      icon-192.png, icon-512.png, README.txt,
      PANDUAN-GITHUB.txt, PANDUAN-PLAYSTORE.txt,
      PANDUAN-BACKUP-CLOUD.txt, PANDUAN-NOTIF.txt,
      CHECKLIST-UPDATE.txt, main.py, install.sh, start.sh,
      package.json, vercel.json
   File lama yang namanya sama OTOMATIS KETIMPA.
5. Drag FOLDER-FOLDER ini sekalian (yang sudah ada di
   repo juga boleh ditimpa isi barunya):
      lib/  api/  .well-known/
   → folder .well-known WAJIB ada di repo biar app Play
     Store full screen. Zip v2.10 udah nyertain foldernya.
   (GitHub otomatis meng-upload isi foldernya).
   Kalau foldernya SUDAH ada di repo → lewati, nggak usah.
   CATATAN v2.9: folder api/ WAJIB ada di repo — folder ini
   MESIN BACKUP CLOUD OTOMATIS (isinya ping.js & backup.js).
   Tanpa folder ini, backup cloud memang tidak jalan
   (app akan bilang "SERVER CEK ENV"). Push sekali, selesai.
6. Klik "Commit changes" (pesan bebas, mis. "update v2.9").
7. Tunggu ±1 menit → Vercel deploy ulang sendiri. Beres.

   TRICK bikin folder di GitHub: pas "Create new file",
   ketik namanya pakai garis miring — contoh ketik
      api/ping.js
   → GitHub otomatis bikin folder "api/" buat kamu.

== CARA B — LEWAT TERMUX (paling cepet, 4 perintah) ==
Simpan zip Miapos ke HP, lalu di Termux:

   cd ~/miapos
   unzip -o ~/storage/downloads/miapos-v2.9.zip
   git add -A
   git commit -m "Miapos v2.9"
   git push

   (-o = timpa semua file lama langsung di tempat. Zip
   Miapos TANPA folder pembungkus, jadi extract langsung
   nimpa dengan benar — termasuk bikin folder api/ kalau
   belum ada.)
   (git add -A = masukin SEMUA perubahan: file baru,
   file ketimpa, dan file kehapus. Jadi nggak perlu mikir
   file mana yang berubah.)
   Kalau push ditolak "rejected" → pakai: git push --force

== CARA B KALAU ADA FILE BARU (contoh: folder api/) ==
Sama persis kayak di atas! Zip terbaru tinggal di-extract
pakai unzip -o, folder api/ ikut kebikin sendiri kalau
belum ada, terus git add -A nyiderek semuanya. Cukup.
Kamu nggak perlu hafal file mana yang baru — yang penting
zip-nya yang TERBARU.

==========================================================
APP DI HP: GAK PERLU UNINSTALL-UNINSTALL LAGI
==========================================================

Ini penting biar tenang:

1. App yang ke-install di HP (via Chrome "Tambahkan ke layar
   utama" / APK PWABuilder) itu CUMA "cangkang"-nya.
   Isinya (index.html dll) diambil dari Vercel.
2. Kamu push ke GitHub → Vercel deploy → app di HP otomatis
   ambil versi baru pas dibuka pakai internet → reload
   sendiri. TANPA uninstall. TANPA install ulang. SELAMANYA.
3. Cuma 1 kasus yang butuh ganti APK: kalau kamu MAU memperbarui
   APLIKASI DI PLAY STORE-nya. Caranya: bikin APK/AAB baru di
   PWABuilder (tinggal next-next, URL Vercel sama) → upload
   ke Play Console sebagai update (naikkan versionCode).
   Pengguna Play Store dapat update dari Play. Yang install
   langsung dari APK juga tinggal install APK barunya
   DI ATAS yang lama (data aman, nggak perlu uninstall dulu).

VERCEL: nggak ada settingan tambahan. Repo ke-update →
Vercel deploy sendiri. (Khusus BACKUP CLOUD: sekali aja
set env GITHUB_TOKEN + BACKUP_KEY — ikut
PANDUAN-BACKUP-CLOUD.txt. Sekali set, selamanya.)

==========================================================
SETELAH PUSH — AUTO-UPDATE JALAN SENDIRI
==========================================================
- Vercel deploy ulang otomatis (±1 menit).
- App di HP pengguna: begitu dibuka pakai internet, service
  worker ambil versi terbaru lalu reload sendiri. Tanpa
  internet tetap jalan dari cache (masih bisa dipakai).
- Cek versi sudah masuk apa belum: buka app → Pengaturan →
  scroll paling bawah → tertulis "Miapos F&B Suite v2.9".
- Kalau repo lagi kena merge conflict (web tampil <<<<<<<),
  cara nimpa di atas sekalian menyembuhkannya — index.html
  yang bersih menimpa yang conflict.

SEKALI SAJA — LOGIN GITHUB DI TERMUX
------------------------------------
   git config --global user.name "Nama Kamu"
   git config --global user.email "email@kamu.com"
   git config --global credential.helper store

(Gunakan Personal Access Token sebagai password, bukan
password akun: github.com → Settings → Developer settings →
Personal access tokens → Generate new token (classic) →
centang "repo" → copy token-nya)

PUSH PERTAMA KALI (jalankan di folder miapos)
---------------------------------------------
   cd ~/miapos
   git init
   git add .
   git commit -m "Miapos v2.9 - full offline"
   git branch -M main
   git remote add origin https://github.com/USERNAME/miapos.git
   git push -u origin main
   (nanti diminta Username + Password → paste TOKEN tadi)
   (PASTIKAN folder lib/ dan api/ ikut ke-push — cek di web
    GitHub, harus ada 2 folder itu di repo kamu)

BONUS 2 — DEPLOY KE VERCEL (sekali aja, 2 menit)
==========================================================
   1. Buka vercel.com → login pakai akun GitHub
   2. Add New → Project → pilih repo "miapos"
   3. Framework Preset: OTHER (biarkan default, tanpa build)
   4. Deploy → selesai!
   Karena file utamanya sudah bernama index.html, Vercel
   otomatis mendeteksi & menampilkannya di URL root:
   https://miapos-kamu.vercel.app
   Setiap git push baru → Vercel auto-deploy ulang sendiri.
   Mau aktifin BACKUP CLOUD? Set env GITHUB_TOKEN +
   BACKUP_KEY di Vercel → ikut PANDUAN-BACKUP-CLOUD.txt.

==========================================================
PENTING — FIX "MERGE CONFLICT" (web tampil tulisan
<<<<<<< HEAD ======= >>>>>>> bukan aplikasinya)
==========================================================
Ini terjadi kalau file index.html di GitHub berisi TANDA
CONFLICT yang belum diresolve (biasanya gara-gara merge /
pull yang bentrok). Solusi paling gampang: TIMPA aja
index.html-nya pakai versi terbaru, lalu push ulang:

   cd ~/miapos
   (timpa index.html + seluruh isi folder dengan versi
    terbaru dari zip Miapos yang lu download — JANGAN
    lupa sw.js, file kecil ini yang bikin app auto-update)
   git add -A
   git commit -m "Miapos v2.9 - timpa bersih"
   git push

Kalau Terminal masih bilang "All conflicts fixed but you
are still merging" → perintah di atas sudah benar, commit
itu juga yang menyelesaikan merge-nya.
Setelah push, Vercel otomatis deploy ulang (tunggu ±1 menit).

Jangan pernah edit index.html pakai aplikasi yang bisa
nyisipin tulisan <<<<<<< di file — kalau ragu, selalu timpa
pakai file asli dari zip Miapos.

==========================================================
BONUS 3 — AUTO-UPDATE (sudah aktif, tanpa setting)
==========================================================
Mulai v2.5, Miapos pakai SERVICE WORKER (file sw.js):
- Setiap app dibuka dengan internet → otomatis ambil versi
  terbaru dari Vercel, lalu reload sendiri.
- Tanpa internet → jalan dari cache, tetap bisa dipakai.
- Lu cukup push/timpa file ke GitHub. Selesai. Semua HP
  pengguna otomatis ke-update dalam ±1 menit.
- Kalau mau pasti-in versi sudah masuk: buka app → Pengaturan
  → scroll paling bawah → tertulis "Miapos F&B Suite v2.9".
