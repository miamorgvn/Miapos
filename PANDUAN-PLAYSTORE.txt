================================================
  MIAPOS — CARA RILIS KE PLAY STORE
  (pakai PWABuilder — gratis, tanpa ngoding)
================================================

KENAPA BISA?
------------
Miapos v2.5 sudah PWA lengkap (manifest.json + sw.js).
Aplikasi web yang sudah PWA bisa dibungkus jadi aplikasi
Android asli (format TWA / Trusted Web Activity) terus
diupload ke Play Store. Isinya tetap Miapos kamu yang
live di Vercel.

BONUS TERBESARNYA:
Setelah rilis di Play Store, setiap kali lu push versi baru
ke GitHub → Vercel deploy → SEMUA pengguna yang install dari
Play Store langsung ke-update sendiri dalam ±1 menit.
TIDAK PERLU upload ulang APK/AAB tiap update (untuk update
biasa). mantep kan.

YANG DIPERSIAPIN
----------------
1. URL Vercel yang udah jalan, contoh:
   https://miapos-kamu.vercel.app
2. Kartu debit/kredit untuk bayar akun Google Play Console
   (US$25 SEKALI aja, bayar seumur hidup, bukan langganan)
3. Email Gmail untuk daftar Play Console

LANGKAH 1 — BUAT AKUN PLAY CONSOLE
----------------------------------
   1. Buka play.google.com/console
   2. Daftar pakai Gmail → bayar $25 (sekali saja)
   3. Selesaikan identitas & verifikasi

LANGKAH 2 — PAKET APLIKASI VIA PWABUILDER (gratis)
--------------------------------------------------
   1. Buka https://www.pwabuilder.com
   2. Paste URL Vercel lu → klik Start
   3. Tunggu analisis selesai (skor manifest & service
      worker Miapos sudah bagus, aman)
   4. Klik "Package for stores" → pilih ANDROID
   5. Isi form:
      - Package ID   : com.miapos.app (atau com.namalu.miapos)
      - App name     : Miapos
      - Version      : 1.0.0.0
      - Start URL    : biarkan default (otomatis /index.html)
      - Theme/color  : #059669
      - Manifest URL : otomatis terisi
   6. Klik Generate → download ZIP berisi:
      - app-release-signed.aab  ← INI YANG DIUPLOAD KE PLAY
      - assetlinks.json         ← langkah 3 di bawah
      - signing key             ← SIMPAN AMAN! jangan hilang,
        jangan share. Kalau hilang = tidak bisa update app.

LANGKAH 3 — UPLOAD assetlinks.json KE REPO
------------------------------------------
Supaya app tampil full tanpa address bar Chrome.

!! PENTING, BIAR GA BINGUNG !!
Dalam ZIP PWABuilder itu file assetlinks.json ada
LANGSUNG di dalam ZIP (sejajar file AAB), TIDAK ADA
folder .well-known. Memang begitu — bukan salah download.
Folder .well-known itu harus kita BIKIN SENDIRI di GitHub.
Kenapa harus nama segitu? Karena Android WAJIB file ini
terbaca di alamat persis:
   https://url-lu/.well-known/assetlinks.json
Itu standar web yang gak bisa diganti. Jadi intinya:
file-nya dari ZIP, folder-nya kita bikin di GitHub.

CARA PALING GAMPANG (GitHub web, tanpa Termux):
   1. Ekstrak ZIP PWABuilder → buka assetlinks.json
      pakai text editor → copy SEMUA isinya.
   2. Buka repo GitHub lu → Add file → Create new file.
   3. Di kotak nama file, ketik PERSIS begini:
         .well-known/assetlinks.json
      Begitu lu ngetik tanda "/", GitHub OTOMATIS
      bikin folder .well-known-nya (ada tulisan
      "this will create a new folder").
   4. Paste isi JSON yang tadi di-copy ke kotak besar.
   5. Klik Commit changes. Sekali jalan: folder + file
      langsung jadi di root repo, sejajar index.html.
   6. Tunggu Vercel deploy (±1 menit), terus cek buka:
      https://URL-VERCEL-LU/.well-known/assetlinks.json
      Kalau muncul isi JSON-nya = beres, bener.

INI KUNCI FULLSCREEN (GAK ADA TOPBAR CHROME):
App dari PWABuilder itu TWA. Saat dibuka, Android ngecek
ke alamat .well-known/assetlinks.json tadi: "app ini
beneran pemilik domain Vercel-nya gak?"
   - File ada & cocok  → app FULL, topbar Chrome
     GAK MUNCUL sama sekali (kayak app asli).
   - File gak ada/salah → Chrome jalanin sebagai
     "custom tab" → bar Chrome ikut muncul.
Jadi selama langkah di atas bener, fullscreen pasti dapet.

CARA TES CEPAT TANPA PLAY STORE:
   Kalau di ZIP PWABuilder ada file berakhiran .apk,
   tinggal copy ke HP → buka file-nya → install
   (izin "install dari sumber tidak dikenal"). Buka
   app-nya: kalau assetlinks.json sudah live, app
   langsung FULL, topbar Chrome GAK MUNCUL.
   Catatan: kalau app ke-install SEBELUM file-nya
   live, uninstall dulu terus install lagi (Android
   nyimpen cache verifikasi).

CARA TERMUX (kalau lebih suka lewat HP terminal):
   1. Copy assetlinks.json dari ZIP tadi ke folder
      repo lu di storage HP.
   2. Jalankan:
      cd miapos
      mkdir -p .well-known
      cp assetlinks.json .well-known/
      git add . && git commit -m "assetlinks" && git push

NOTE KALAU ADDRESS BAR MASIH MUNCUL JUGA:
Play Console kadang re-sign app pakai kunci mereka
(Play App Signing) sehingga fingerprint beda dari yang
di assetlinks.json. Solusinya:
   1. Play Console → Setup → App signing → copy
      SHA-256 "App signing key certificate".
   2. Edit assetlinks.json di repo: tambahkan SHA-256
      itu ke daftar sha256_cert_fingerprints (dipisah
      koma — boleh berisi lebih dari 1 fingerprint).
   3. Commit → push. Vercel deploy lagi, beres.

LANGKAH 4 — UPLOAD KE PLAY CONSOLE
----------------------------------
   1. Play Console → Create app
      - Nama app  : Miapos
      - Default   : Indonesia, Free
   2. Isi form wajib (semua gratis, cuma njawab form):
      - App content: privacy policy, content rating,
        target audience, iklan (pilih "no ads"), dll.
      - Privacy policy URL: wajib punya halaman web. Trik
        gampang: buat file privacy.html sederhana di repo
        lu, jadi URL-nya https://url-vercel-lu/privacy.html
        (isi: nama app, data disimpan di HP sendiri, tidak
        dikirim ke server mana pun — memang itu faktanya)
   3. Production → Create new release → upload file
      app-release-signed.aab
   4. Isi store listing: nama, deskripsi singkat, screenshot
      HP (screenshot aja app Miapos lu), ikon 512x512
      (pakai icon-512.png dari folder Miapos)
   5. Submit for review. Review Google biasanya 1-7 hari.
   6. Setelah APPROVED → app live, semua orang bisa install!

-----------
   - PWABuilder      : GRATIS

PERLU DIINGAT
-------------
   - JANGAN sampai kehilangan signing key dari PWABuilder.
     Simpan di 2 tempat (HP + Google Drive).
   - Update versi BESAR (ganti package ID dll) = upload AAB
     baru. Update biasa (isi/fitur web) = cukup push GitHub,
     auto-update menangani semuanya.
   - Play Store minta aplikasi "punya perilaku minim" untuk
     TWA — Miapos aman karena ini app bisnis biasa, bukan
     game/sistem file.
   - Alternatif TANPA Play Store (juga gratis): bagikan URL
     Vercel lu → orang buka di Chrome → menu ⋮ →
     "Tambahkan ke layar utama" → jadi ikon app sendiri,
     tampilannya sama persis kayak APK.
